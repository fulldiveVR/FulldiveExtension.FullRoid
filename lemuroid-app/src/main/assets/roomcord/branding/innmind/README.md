# InnMind web assets

These files mirror the metadata assets linked from `https://innmind.com/`:

- `favicon.png`: the source 32×32 favicon
- `Icon-192.png`: the source 192×192 site icon
- `apple-touch-icon.png`: the source 180×180 Apple touch icon
- `tile-icon.png`: the source 270×270 Microsoft tile icon
- `logo.png`: the organization logo referenced by the page schema
- `header-logo.svg`: the horizontal logo used by InnMind's site header
- `og-default.webp`: the source 1200×630 Open Graph image

The 512px and maskable filenames are derived from the 192px site icon so the
Flutter PWA manifest has a complete icon set.
